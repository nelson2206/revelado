# Revelado (vitrina)

Copia estática de la web de socios y de la boda de demostración de Revelado: retos de fotos por QR, ranking en vivo y álbum que se revela al final.
Esta vitrina no guarda datos. La aplicación completa (con servidor) se publica aparte.
